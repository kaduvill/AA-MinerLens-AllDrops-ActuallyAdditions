# AA Miner Lens - All Drops

A tiny Minecraft 1.12.2 client-side addon for Actually Additions 1.12.2-r152 and JEI/HEI 4.x.

Adds separate all-drops categories for the Lens of the Miner in stone and netherrack, using the loaded configuration. Drops are indexed as recipe outputs, with chances shown in tooltips. The range is displayed below the output grid.

Aim: QoL for recipe-transfer helpers that can fill an entire filter.
